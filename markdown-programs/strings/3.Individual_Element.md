# Individual Element

**C source:** `c-programs/strings/3.Individual_Element.c`

## C Source Code

```c
#include<stdio.h>

void indiElement(char *str)
{
	int i=0;
	while(str[i]!='\0')
	{
		printf("string [%d] character = %c\n",i+1,str[i]);
		i++;
	}
	printf("\n");
}

int main()
{
	char str[30];
	printf("Enter a string : ");
	fgets(str,sizeof(str),stdin);
	indiElement(str);
return 0;
}
```
