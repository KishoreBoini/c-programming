# Post And Pre Increments Decrements

**C source:** `c-programs/pointers/7.Post_and_Pre_Increments_Decrements.c`

## C Source Code

```c
#include<stdio.h>

void main()
{
	int val=5;
	int *ptr;
	ptr=&val;
	printf("Actual value %d\n",val);
	printf("Pre Incremant %d\n",++(*ptr));
	++(*ptr);
	printf("Pre Incremant %d\n",*ptr);
	printf("post Incremant %d\n",(*ptr)++);
	(*ptr)++;
	printf("Post Increment %d\n",*ptr);

}
```
