# String Length

**C source:** `c-programs/pointers/21.String_Length.c`

## C Source Code

```c
#include<stdio.h>

int stringLength(char *ptr)
{
	int count=0;
	while((*ptr)!='\0')
	{
		count++;
		ptr++;
	}
return count;
}


void main()
{
	char str[20];
	int len;
	printf("Enter the String : ");
	scanf("%s",str);
	len=stringLength(str);
	printf("Length of the given String is : %d\n",len);
}
```
