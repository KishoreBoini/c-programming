# 44.Program_to_invoke_a_function_using_function_pointer

**C source:** `c-programs/pointers/44.Program_to_invoke_a_function_using_function_pointer.c`

```c
#include<stdio.h>

int Add(int a,int b)
{
	return a+b;
}

int main()
{
	int (*ptr)(int,int)=&Add;
	int ret=ptr(10,4);
	printf("sum = %d\n",ret);
return 0;
}
```
