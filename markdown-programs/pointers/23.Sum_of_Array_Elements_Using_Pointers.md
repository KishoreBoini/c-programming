# Sum Of Array Elements Using Pointers

**C source:** `c-programs/pointers/23.Sum_of_Array_Elements_Using_Pointers.c`

## C Source Code

```c
#include<stdio.h>

void SumofElements(int *ptr,int *sum,int len)
{
	for(int i=0;i<len;i++)
	{
		(*sum)+=ptr[i];				
	}
}

void main()
{
	int arr[5],sum=0;
	printf("Enter the array : ");
	for(int i=0;i<5;i++)
	{
		scanf("%d",&arr[i]);
	}
	SumofElements(arr,&sum,5);
	printf("Sum of the Array Elements : %d\n",sum);
}
```
