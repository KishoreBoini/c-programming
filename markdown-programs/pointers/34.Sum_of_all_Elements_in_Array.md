# Sum Of All Elements In Array

**C source:** `c-programs/pointers/34.Sum_of_all_Elements_in_Array.c`

## C Source Code

```c
#include<stdio.h>

void ArrSum(int *ptr,int *sum,int len)
{
	for(int i=0;i<len;i++)
	{
		*sum+=*(ptr+i);
	}
}

int main()
{
	int arr[5],sum=0;
	printf("Enter Array Elemets : ");
	for(int i=0;i<5;i++)
	{
		scanf("%d",&arr[i]);
	}
	ArrSum(arr,&sum,5);
	printf("Sum of Array = %d\n",sum);
}
```
