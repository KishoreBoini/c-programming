# 14.Printing_matrix_Elements_using_pointer

**C source:** `c-programs/pointers/14.Printing_matrix_Elements_using_pointer.c`

```c
#include<stdio.h>

void main()
{
	int mat[2][2]={{1,2},{3,4}};
	int (*ptr)[2];
	ptr=mat;
	for(int i=0;i<2;i++)
	{
		for(int j=0;j<2;j++)
		{
			printf("%d ",ptr[i][j]);
		}
	
	}
	printf("\n");
}
```
