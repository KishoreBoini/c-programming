# C Programming Practice

A collection of C programming practice programs covering fundamental
concepts, problem-solving techniques, and data structures.

This repository documents my learning and practice journey in C programming.

## Repository Structure

### 1. C Programs

Contains the original, compilable `.c` source files organized by topic.

[Browse C Programs](./c-programs/)

### 2. Markdown Programs

Contains the corresponding `.md` versions of the programs.
Each file displays the C source code in a formatted code block for easy
reading directly on GitHub.

[Browse Markdown Programs](./markdown-programs/)

### 3. Tools

Utility scripts used to manage and maintain the repository.

-convert_to_md.py – Converts C source files into formatted Markdown files.

## Topics Covered

- Arrays and 2D Arrays
- Control Statements
- Pointers
- Strings
- Functions
- Structures and Unions
- Data Structures
- File Handling

## Compiling and Running

Compile a C program using GCC:

```bash
gcc program.c -o program
./program
```
