## Compiling and running C programs

You need a C compiler such as GCC.

On Ubuntu or another Debian-based Linux distribution, install GCC with:

```bash
sudo apt update
sudo apt install build-essential
```

Compile a C source file:

```bash
gcc program.c -o program
```

Run it:

```bash
./program
```

Replace `program.c` with the name of your C source file.
